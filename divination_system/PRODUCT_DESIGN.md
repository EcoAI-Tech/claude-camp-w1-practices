# 「天机阁」智能命理系统 — 产品设计与商业化方案

> 融合周易八卦、四柱八字、西方占星、血型性格与 MBTI 人格测评的一站式
> 数字化命理产品。定位为**传统文化娱乐 + 心理陪伴**服务，可执行、可落地、可变现。

---

## 1. 产品概述

### 1.1 一句话定位

「东方玄学 × 现代心理测评」的个人成长陪伴工具——用严肃的算法引擎和
温暖的解读体验，满足年轻人"求确定感"的情绪消费需求。

### 1.2 核心洞察

- 玄学消费已成为 Z 世代的"情绪刚需"：求签、塔罗、星座 App、水晶手串常年
  占据小红书/抖音热门话题；用户买的不是预测，而是**心理按摩与决策安慰**。
- 现有产品两极分化：老牌算命网站体验陈旧、信任感差；星座 App 内容同质化。
  **"多体系交叉验证"的融合报告是市场空位**——八字说你缺火、星座说你是狮子、
  MBTI 说你是 ENTJ，三方互相印证的叙事天然更有说服力。
- 命理天然自带**高客单、高复购、强裂变**属性：人生节点（升学、跳槽、婚恋、
  置业）都是付费触发点；"帮我看看我对象"就是裂变入口。

### 1.3 目标用户

| 用户群 | 画像 | 核心场景 | 付费意愿 |
|---|---|---|---|
| 泛玄学女性用户（主力） | 18-35 岁，一二线，小红书重度用户 | 感情合盘、日运打卡 | ¥9.9-99/次 |
| 职场决策焦虑者 | 25-40 岁，跳槽/晋升节点 | 事业流年、择日 | ¥99-399/次 |
| 宝妈/婚恋人群 | 结婚、起名、育儿 | 合婚、宝宝起名 | ¥199-999/次 |
| 企业/商家 | 门店、直播间、活动方 | 引流互动工具 | API/年费授权 |

## 2. 产品功能架构

### 2.1 五大测算引擎（本仓库 MVP 已实现前四个的核心算法）

1. **八字命盘引擎**（`bazi.py`）：四柱排盘、五行旺缺分析、喜用神建议。
   商业版接入天文历法库（真太阳时、精确节气），并叠加大运/流年模块。
2. **周易起卦引擎**（`iching.py`）：梅花易数时间卦 + 金钱课摇卦，64 卦
   全卦象断语库 + 动爻提示。App 端做成"摇一摇"仪式感交互。
3. **占星引擎**（`astrology.py`）：MVP 为太阳星座；商业版扩展上升/月亮
   星座、行星相位、合盘。
4. **人格引擎**（`personality.py`）：血型性格 + MBTI 快测；商业版升级为
   标准量表并沉淀用户人格档案。
5. **AI 解读引擎**（商业版）：以规则引擎输出的结构化结果为素材，调用
   LLM（Claude API）生成千人千面的自然语言解读与追问式对话，
   这是与传统算命网站拉开体验差距的关键。

### 2.2 融合报告（核心卖点，`report.py`）

- 四体系结果加权融合，输出事业/财富/感情/健康四维评分 + 综合叙事。
- **评分确定性**：同一用户同一天结果稳定可复现（哈希种子），这是建立
  "准"的信任感与日更打卡习惯的产品底线——分数随机跳变会立刻穿帮。
- 报告分层：免费版给结论摘要，付费版解锁完整命盘、流年细节与化解建议。

### 2.3 产品形态与路线图

| 阶段 | 周期 | 形态 | 里程碑 |
|---|---|---|---|
| MVP | 第 1-2 月 | 微信小程序/H5 + 本引擎 | 日运打卡 + 免费快测 + 付费报告，跑通支付 |
| V1.0 | 第 3-4 月 | 小程序 + 公众号私域 | AI 对话解读、合盘功能、会员订阅 |
| V2.0 | 第 5-8 月 | App + 咨询师平台 | 真人 1v1 连麦咨询、内容社区 |
| V3.0 | 第 9-12 月 | 开放平台 | 测算 API、白标授权、电商周边 |

### 2.4 技术架构（商业版）

```
微信小程序 / H5 / App
        │
   API 网关（鉴权/限流/风控）
        │
 FastAPI 业务后端 ──── 支付（微信支付/支付宝）
        │
 ┌──────┼──────────┐
 测算规则引擎    LLM 解读服务      用户档案库
 (本仓库算法     (Claude API,      (PostgreSQL,
  的服务化)      提示词模板+RAG    命盘缓存 Redis)
                 命理知识库)
```

- 规则引擎负责"算得对"（确定性、可审计），LLM 负责"说得好"（个性化、
  有温度），二者分离是内容质量与成本可控的关键。
- 所有生辰、测评数据属敏感个人信息，需加密存储、脱敏后才可进入 LLM 上下文。

## 3. 商业模式与变现路径（六层漏斗）

| 层级 | 产品 | 定价 | 作用 |
|---|---|---|---|
| ① 免费引流 | 每日运势打卡、星座速配、摇一摇求签 | ¥0 | 拉新 + 日活习惯 |
| ② 轻付费 | 单项深度报告（八字详批/月度运势/合盘） | ¥9.9-39.9 | 首单转化，验证付费意愿 |
| ③ 订阅会员 | 天机会员：无限 AI 追问、周报、择日提醒 | ¥29/月，¥199/年 | 稳定现金流（核心） |
| ④ 高客单咨询 | 真人命理师/心理咨询师 1v1（平台抽成 30%） | ¥199-1999/次 | 客单价天花板 |
| ⑤ 电商周边 | 五行手串、开运礼盒、新年运势日历 | ¥69-599 | 报告内"补火建议"天然带货 |
| ⑥ B 端授权 | 测算 API、直播间互动插件、白标小程序 | ¥3-10 万/年 | 规模化收入 |

**单位经济模型（保守估算）**：小红书内容获客成本约 ¥5-15/注册；
免费→付费转化率参照同品类 3-8%；会员月流失率控制在 15% 以内时，
单用户 LTV ≈ ¥80-150，ROI 可打正后再放大投放。

### 增长策略

- **内容矩阵**：小红书/抖音账号做"每周运势""MBTI×星座"人格切片内容，
  评论区钩子引流小程序。
- **裂变机制**：生成高颜值命盘海报（含二维码）；"合盘"功能天然需要拉
  另一个人进来测。
- **节点营销**：新年运势（流量最大峰值）、水逆、七夕合盘、高考择日。
- **私域沉淀**：公众号 + 企微社群做日运推送与咨询转化。

## 4. 合规与风险控制（决定生死，必须前置）

1. **定位红线**：产品对外统一表述为"传统文化娱乐与心理测评参考"，
   所有报告页脚固定免责声明（MVP 已内置），**严禁**宣传"改命、治病、
   消灾、保证结果"等封建迷信与虚假宣传话术（广告法风险）。
2. **平台审核**：微信对"占卜类"小程序审核趋严，类目建议申报"文化娱乐/
   心理测评"，支付项命名为"报告解锁/会员服务"而非"算命"。准备 H5 +
   App 双通道对冲下架风险。
3. **隐私合规（PIPL）**：生辰、血型属个人敏感信息——单独授权弹窗、
   最小化收集、支持注销删除；未成年人禁用付费功能。
4. **内容安全**：AI 解读输出需过安全过滤（禁涉医疗诊断、投资建议、
   生死预言）；1v1 咨询师需签约管理并全程留痕。
5. **心理边界**：对高频重度使用、情绪低落信号用户，主动推送心理援助
   提示——既是社会责任，也是品牌护城河。

## 5. 关键指标（北极星：付费会员数）

- 拉新：注册成本 CAC、内容曝光→注册转化率
- 激活：完成首次完整测算比例（目标 >60%）
- 留存：日运打卡 7 日留存（目标 >25%）
- 变现：免费→首单转化率（>4%）、会员续费率（>70%）、ARPPU
- 裂变：K 因子（合盘邀请带来的新增/老用户）

## 6. MVP 代码说明

本目录即产品的算法核心 MVP，零依赖、Python 3 可直接运行：

```bash
python main.py          # 交互模式：输入生辰、血型、答 8 题、起卦
python main.py --demo   # 演示模式：内置样例一键出完整报告
```

| 文件 | 职责 |
|---|---|
| `bazi.py` | 八字排盘 + 五行分析 |
| `iching.py` | 梅花易数/金钱课起卦 + 64 卦断语库 |
| `astrology.py` | 太阳星座判定 + 元素解读 |
| `personality.py` | 血型性格 + 8 题 MBTI 快测 |
| `report.py` | 四体系融合报告与确定性评分 |
| `main.py` | CLI 入口（商业版替换为 FastAPI 服务） |
